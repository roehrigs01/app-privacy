MassLoop Support

Help for the MassLoop workout logger on iPhone and iPad.

Workouts and templates

Create templates with exercises and sets, start a workout, record completed weights and repetitions, and finish to save your history. Use Add Template from File to import a supported UTF-8 text template. Import instructions and a sample are available in Settings → Help.

Manual and Auto sets

Choose Manual to set all values yourself. Auto calculates W1 (40% × 10), W2 (60% × 8), Set 1 (75% × 5), Set 2 (85% × 3+), and H hypertrophy (65% × 15+) using estimated one-rep max. You can adjust Set 2 load; other Auto weights recalculate. Seven or more completed repetitions on Set 2 raise the next prescription by 5 lb for dumbbell exercises or 10 lb for barbell exercises.

iCloud backup

Settings → iCloud Backup provides manual Back Up to iCloud and Restore from iCloud actions. Sign in to iCloud, enable iCloud Drive, and ensure MassLoop has iCloud access. Restoring replaces local data. Backups are not automatic sync.

Rest notifications

Enable rest completion sound in Settings → Workout Preferences and allow notifications in device Settings.

Purchases

MassLoop offers a 90-day trial and an optional lifetime Pro unlock. Use Restore Purchases in Settings to restore a prior purchase with the same Apple Account.

Device and layout support

MassLoop supports iPhone, iPad, and adaptable layouts for iPhone Duo. Include device model, OS version, app version, and reproduction steps when reporting a display issue.

Contact support

Open a MassLoop support request (GitHub account required). Issues are public: do not include sensitive information.
